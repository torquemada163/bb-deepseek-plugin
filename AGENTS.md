# Правила проекта

Общайся с пользователем всегда на русском языке. Публичную документацию и интерфейс плагина поддерживай на английском по образцу bb-kimicode-plugin.

Поддерживай актуальным локальный `MEMORY.md`: записывай решения, выполненную работу, результаты проверок и оставшиеся задачи, чтобы другой агент мог продолжить по этим двум файлам.

Когда пользователь говорит, что заканчиваем сессию:

- Закоммить незакоммиченные изменения, исключив секреты и генерируемые файлы.
- Актуализируй `MEMORY.md`.
- Дай промпт на следующую сессию.

## Ограничения реализации

- Независимый провайдер `deepseek`; не менять Kimi, Claude Code, Codex или глобальную конфигурацию OpenCode.
- Ключ из `.env` читать только на хосте. Никогда не печатать его, не класть в Git, provider options, CI или публичные артефакты.
- Использовать только публичный Plugin SDK bb. SDK и bb-app обновлять согласованно.
- Не публиковать, не пушить и не создавать релиз без указания пользователя.
- Перед поставкой: `npm run typecheck`, `npm test`, `npm run build`, `npm run check:install`, `npm run check:package`.
- Реальные API smoke-проверки платные; не включать их в CI. Проверять в временной папке, исключая секреты из логов.
